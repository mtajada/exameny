# Clean-room declaration

## Scope

All visible educational prose, questions, answer options, explanations, learner samples, rubrics, coaching dialogues, safety cases, and model prompts in this directory were authored for this clean-room package on 2026-08-26.

OpenAI Codex drafted the material under Miguel Tajada Ferrer's direction. The
file-level manifest records that assistance, creation date, levels, skills, and
technical review. Publication remains conditional on Miguel's human review and
adoption of the material and its CC-BY-4.0 licensing.

The authoring process used only:

- general knowledge of English grammar, vocabulary, reading, and writing pedagogy;
- the broad B1, B2, C1, and C2 proficiency labels;
- invented people, places, organizations, events, and scenarios;
- the minimum field-level software contracts required by Exameny's eight existing interface layouts.

No private exercise corpus, scanned page, OCR output, handbook, answer key, examiner rubric, generated cache, or existing generation, evaluation, or chat prompt was used as a source. No old exercise was paraphrased, translated, rearranged, or lightly modified.

## Compatibility consultation

Compatibility work was limited to the names and primitive shapes of layout fields, such as question numbers, placeholders, answer arrays, option arrays, and text-section arrays. Subject matter, wording, pedagogy, answers, distractors, feedback, and evaluation criteria were created independently.

## Independence

This package is not affiliated with, endorsed by, or an official preparation product of any examination provider. It uses no provider names, logos, proprietary task labels, score bands, or claims of equivalence to an official exam.

## Review gates

Before release, a reviewer must confirm:

1. every content file is listed in `provenance.json`;
2. repository-wide searches find no excluded third-party material in the public export;
3. no personal information, credentials, private URLs, or infrastructure identifiers are present;
4. the public repository begins from a sanitized snapshot rather than private Git history;
5. the chosen repository license is supported by code and contributor rights.
